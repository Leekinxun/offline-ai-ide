# Web Agent 编辑工作流

这次改造把上下文选择、代码提案、落盘改动审阅、验证、预览和后台任务接入同一工作台。沿用现有权限、Mutation Journal、运行记录及上下文策略，没有增加运行时依赖。

## 已实现能力

| 模块 | 使用方式及行为 |
| --- | --- |
| 安全编辑 | `read_file` 返回版本和分页信息；覆盖必须基于已读取内容或显式版本。`edit_file` 要求唯一匹配，支持受控换行归一化，拒绝过期、歧义和未完整读取的覆盖。未保存的编辑器内容保留，磁盘变化显示冲突。 |
| 改动账本与撤销 | 每次修改保存不可变前后内容；审核关联具体 run、request 和 revision。可撤销文件、块或上一回合；上一回合撤销会从之前的对话上下文创建分支，保留原对话与审计记录。冲突时不覆盖后续修改。 |
| 编辑器内提案 | 选区或光标处按 Cmd/Ctrl+K，输入要求，流式查看原文与候选代码。Esc 取消；生成完整且原始编辑器版本仍一致时才可接受。接受只修改 buffer，可 Cmd/Ctrl+Z 撤销，再由用户保存。 |
| 持续审阅 | 主编辑器展示尚未确认的已落盘改动；保留后收起对应红绿标记，全部确认后恢复干净的编辑视图。完整变更面板保留历史差异、文件统计、逐文件/逐块撤销和带版本、行号的反馈。 |
| 显式上下文 | 两个对话输入入口支持 `@file`、`@folder`、`@symbol`、`@selection`、`@problems`、`@terminal`，可移除引用 chip。服务端重新检查读权限、排除项、版本和预算；Inline 请求也使用当前选区及已选引用。 |
| 计划与问题 | 计划卡完整展示目标、文件、步骤、风险、命令和验收标准，可提出修订。Agent 的结构化问题支持选项、自由回答和跳过，切换对话或浏览器重连后仍可回答。 |
| 验证与修复 | 修改后收集相关检查命令和诊断；缺失或失败时最多两轮自动修复反馈，命令仍经过权限检查。验证证据绑定修改版本，后续修改会使旧通过结果失效。 |
| 命令会话 | Agent 可启动、轮询、输入和停止受控长命令；运行中心展示会话输出、输入与状态。取消 run 清理其 Agent 进程。网络默认禁用；管理员显式启用后，联网命令仍须逐次批准。 |
| Web 预览 | 左侧 Web 预览入口支持静态 HTML 和已安装的 Vite 项目；提供受控 HTTP/WebSocket 代理、HMR、错误反馈和元素选择。可验证的 TSX/JSX 源码位置可跳转回编辑器。 |
| 后台任务 | AI 任务列表可切换仍在运行的对话，显示运行/等待操作状态；切回恢复内容、待批准项及问题。同一真实工作区只允许一个主 Code 写入者，独立 worktree 可隔离并行编码。 |

## 典型操作

1. 打开文件，用 `@` 引用其他文件、符号或报错；小范围改写直接选区后 Cmd/Ctrl+K。
2. Inline 候选确认后进入未保存 buffer；Code Agent 的工具修改按批准流程直接落盘。两者在界面上分别标明。
3. 从编辑器红绿区域或任务的“变更”页保留、逐块撤销，或为具体行添加后续修改意见。编辑器的“全部保留”一次确认当前文件；“变更”顶部的“全部保留（N 个文件）”一次确认本轮待审文件。保留会收起编辑区的已确认标记；原始差异及后续撤销仍在“变更”中。
4. 需要回退整次需求时点“撤销上一回合”。系统恢复该回合修改并切到此前上下文，原需求回到草稿中。
5. 在运行中心检查真实命令结果，在 Web 预览中查看效果。选中元素或收集错误后，将反馈送入草稿继续迭代。
6. 可以切换到其他任务；后台等待批准或回答时，列表会显示“等待操作”。

## 能力边界

- 主编辑器展示的是已落盘变更；“保留”表示审阅确认。完整文件事务暂存区没有引入。流式提案只写候选视图，不把不完整 token 写入文件。
- 批量保留绑定点击时的改动版本；新产生的修改仍待确认。列表过期或存在不可审查文件时，整批拒绝并刷新，不自动确认新版本；批量保留不授予工具执行权限。
- 编辑器内按钮仅适用于当前版本、可唯一定位的变更块；旧版、歧义或大文件回到完整变更面板处理。运行中的修改须先停止才能撤销。
- 模糊匹配只允许可证明唯一的受控归一化，不按编辑距离猜测并覆盖代码。多文件撤销有预检和冲突拒绝，但不是操作系统级多文件原子事务。
- Monaco marker 是附加诊断线索。未知来源版本、空 marker 和截断列表不能证明类型检查通过；最终验证依赖真实命令及对应版本证据。没有可运行的检查时会标记未验证。
- `@terminal` 引用最近的运行/测试输出；不读取任意交互式终端的全部历史。
- 待回答问题可在服务仍运行时恢复；服务重启沿用 interrupted-run 恢复，不猜测答案，也不自动继续原来内存中的等待。
- Vite 预览使用受控配置，不加载项目任意 `vite.config`、环境文件或代理配置；依赖自定义插件的项目可能需要自行适配。静态 HTML、Vue 或动态 DOM 未必能映射到源码，界面会明确显示无法定位。
- 预览 Console 错误和元素选择生成显式反馈，不能自行授权新一轮文件写入。iframe 隔离，不共享 IDE 身份。
- 同工作区的多个对话可以后台执行，但不会并行运行两个主 Code 写入者。用户手动启动的运行中心项目任务采用其既有信任边界。
- 验证使用离线固定模型响应、真实文件工具、命令和浏览器，未进行付费模型评测或声称达到竞品相同模型下的成功率。

复现步骤与验证记录见 [浏览器与工程验证](testing/web-agent-upgrade.md)。联网配置与授权边界见 [Agent 显式网络授权](security/agent-network-opt-in.md)。
