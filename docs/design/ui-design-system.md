# CrownForge UI 设计系统与视觉规范 (UI Design System)

> **最后更新时间**：2026-10-01  
> **文档定位**：CrownForge IDE 对外设计系统规范（Design System Specification），定义 IDE 整体视觉调性、色阶阶梯、微光束交互语言、AI 对话输入流与 Web 预览组件契约。

---

## 一、核心设计哲学与愿景 (Design Philosophy)

CrownForge 致力于打造现代化、沉浸式的离线智能 IDE。我们坚决摈弃传统 IDE 密集物理分割线、高饱和单色块与生硬大边框带来的视区压迫感，确立以下五大核心准则：

1. **以色阶明暗递进替代物理画线 (Tone over Line)**：依靠 3%~6% 细腻明度差值自然呈现区块沉降与浮起；
2. **以磨砂蓝微光取代死锁粗实线 (Frosted Blue Halo)**：杜绝 `outline: 2px` 与单调生硬的粗描边，统一采用半透明磨砂漫反射微光；
3. **触感微卡片与真实状态契约 (Tactile Controls & De-fake)**：深邃微卡、消灭无状态“假高亮”蓝点、圆角阶梯矩阵；
4. **流式微胶囊与按需涌现 (@ Context & Capsule Chips)**：拒绝机械死板的静态占位条，输入提示内生于占位符，选中上下文以可消除的微胶囊呈现；
5. **样式物理隔离与工程解耦 (Decoupled CSS)**：严禁无休止向全局样式追加单体代码，组件专用样式就近隔离。

## 二、色阶体系 (Spatial Tone Scale)

| 层级 | CSS 变量 | 代表色阶 (Dark) | 典型应用视区 |
| :--- | :--- | :--- | :--- |
| **Level 0 (沉降基座)** | `--surface-workbench` | `#0d0f12` | 侧边栏活动条 (ActivityRail)、底部状态栏、主视窗深基座 |
| **Level 1 (主工作台)** | `--surface-panel` / `--bg-primary` | `#14171b` | 编辑器主视区、主面板内容区、Iframe 宿主层 |
| **Level 2 (次级面板)** | `--bg-secondary` | `#1a1d22` | 侧边栏文件树、辅助助手栏、面板 Header、卡片背景 |
| **Level 3 (活动微卡/浮层)** | `--surface-panel-strong` / `--bg-surface` | `#22262d` | 活动标签页、下拉浮层、选择器浮窗、对话微卡 |

## 三、AI 对话与 Composer 规范 (AI Chat & Composer)

### 3.1 极简输入框架构
- **无常驻死板工具条**：未添加引用时，输入框内不展示任何占据整行的提示栏；
- **占位引导**：通过 Textarea 占位符提示“键入 @ 引用上下文”；
- **底部集成操作栏**：
  - 左侧：`+` 附件上传微按钮、`@` 上下文微按钮、模式选择器（`WorkbenchSelect`）；
  - 右侧：Token 环形指示器、发送/停止主按钮。

### 3.2 `@` 上下文联想与选择浮层
- **呼出方式**：键盘键入 `@` 触发，或点击底栏 `@` 按钮；
- **分类分组展示**：
  - **工作区上下文**：`@selection`（编辑器选区）、`@problems`（工作区诊断）、`@terminal`（终端输出）；
  - **代码符号**：`@symbol`（工作区符号全局检索）；
  - **文件与目录**：工作区候选文件与目录项；
- **视觉风格**：
  - 半透明毛玻璃卡片（`backdrop-filter: blur(20px)`）；
  - 选中项使用 `color-mix(in srgb, var(--accent) 14%, transparent)` 磨砂微光包裹；
  - 底部指示栏展示键盘导航快捷键（`↑↓ 导航 · Enter 选用 · Esc 关闭`）。

### 3.3 选中引用胶囊 (Capsule Chips)
- 仅当 `references.length > 0` 时展示，不占用多余垂直空间；
- 采用语义色彩图标（选区蓝、诊断橙、终端绿、符号紫、文件灰、目录金）；
- 配备精致平滑的关闭按钮 `×`，支持一键移除。

### 3.4 AI 协作微型上下文环与历史会话管理
- **18px 纯 SVG 环形进度**：侧栏空间紧凑，去除冗长文字，仅以微型环形指示器动态表达上下文消耗比例，鼠标悬停显示精确已用/上限 Tokens 与百分比，点击呼出 ContextInspector；
- **顶部 History 切换**：面板顶部 Header 提供历史记录操作按钮，点击展开历史会话微卡浮动列表，支持一键切换或清理会话；
- **输入区全局字体统一**：消除 `@` 上下文联想与输入框中等宽字体的割裂感，统一继承全局 UI 字体。

## 四、Web 预览面板规范 (Web Preview Panel)

### 4.1 面板 Header
- 左侧：微卡浅蓝底包覆的 `Globe` 图标、标题、状态徽标（Ready 浅绿徽标、Starting 呼吸脉冲蓝光、Stopped 灰徽标）；
- 右侧：检查模式（Inspect，激活时点亮微光）、刷新、在系统浏览器打开（`ExternalLink`）、停止（危险警示悬停）、关闭按钮。

### 4.2 控制与微胶囊地址栏
- **选择器**：全面采用 `WorkbenchSelect`，替代原生丑陋的 `<select>`；
- **微胶囊地址栏**：运行就绪时展示指南针图标、只读 URL 路径、一键复制反馈（`Check` 动画）、外部打开按钮。

### 4.3 品牌级居中深邃空状态
- 杜绝干瘪无排版的左对齐小灰字；
- 采用**居中大圆角微卡**：
  - 大号带蓝光漫反射光晕的圆角图标；
  - 主标题“暂无运行中的 Web 预览”与副说明文案；
  - 启动目标微卡列表（带浅绿 `Play` 图标微卡按钮，hover 浮起微光）。

### 4.4 顶栏布局与多端视图互斥/共存契约
- **顶栏并列定位**：从左侧活动条移至右上顶栏（`TitleBar` 与 `EditorToolbar`），与“AI 协作”按钮并列；
- **代码编辑模式严格互斥**：在 files 视图下，Web 预览与 AI 协作抽屉保持严格互斥（开启预览自动关闭协作，开启协作自动关闭预览；开启代码审查详情时均自动关闭）；
- **任务对话模式并排共存**：在 chat 视图下，支持唤起 Web 预览，右侧 dock 展开 PreviewPanel，实现边对话生成边实时预览。

## 五、控件聚焦与状态规范 (Focus & State Contract)

- **废除 `outline: 2px`**：严禁在任何控件上使用生硬刺眼的 `outline: 2px solid ...`；
- **统一磨砂微光内阴影**：
  ```css
  :focus-visible {
    outline: none;
    box-shadow: 0 0 0 1.5px var(--accent);
  }
  ```
- **微圆角阶梯矩阵**：
  - 4px ~ 6px：小型操作按钮、输入框、下拉框、胶囊标签；
  - 8px ~ 10px：卡片、下拉菜单浮层、对话气泡；
  - 12px ~ 14px：主视窗浮动弹窗、Composer 外壳；
  - 999px：状态圆点、分段胶囊、微光拖拽中缝。

---

## 六、全局滚动条规范 (Global Scrollbar Standard)

- **9px 易触达微轨道**：全局滚动条宽度由过细的 5~6px 升级至 9px，大幅提升鼠标快速移动时的命中与吸附效率；
- **全透明底轨 (Transparent Track)**：背景 100% 透明，杜绝老旧灰黑硬底轨对视区的干扰；
- **微胶囊滑块**：滑块采用 999px 全圆角，平时保持柔和低对比色阶，鼠标悬停与拖拽激活时呈现平滑渐变提亮。
